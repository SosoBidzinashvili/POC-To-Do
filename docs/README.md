# Documentation (`docs/`)

This folder centralizes all **project documentation** so that contributors can quickly understand the architecture, decisions, and workflows.

## Index

- `ARCHITECTURE.md` – high-level overview of the system (backend, frontend, data flow).
- `ENVIRONMENTS.md` – description of local, staging, and production environments.
- `DECISIONS.md` – log of key technical decisions and assumptions.

As the project grows, you can add more documents here (e.g., performance notes, API contracts, UX guidelines).
